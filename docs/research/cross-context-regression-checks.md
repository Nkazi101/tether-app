# Cross-context software checks

`tests/cross-context.test.ts` exercises the publication/display boundary with source-anchored synthetic mechanics. It does not rate real historical analogies or establish that a 25-year gap is an empirical law.

The checks establish that:

- A documented historical ending 24 calendar years before the current report fails the product boundary; 25 passes.
- An early start date or a shortened display label cannot conceal a recent ending in a long historical record.
- Current-event dating comes from the reported account rather than silently using today's server date.
- An explicitly named principal appearing in both current and historical facts is caught even when omitted from the proposed mapping. Honorific normalisation also applies to legacy ordered comparisons.
- Explicit same-person, same-organisation and unresolved identity assessments do not earn the new comparison badge.
- A durable public institution can appear in separate episodes when the proof explicitly establishes that exception. Both ends must qualify as public institutions or polities; private organisations cannot borrow the exception through a mixed mapping.
- A continuing causal episode remains context rather than independent recurrence.
- Identity checks must cover every mapped actor. New-policy readings also need the causal test, and its driver must reference an actual mapping.
- A legitimate distant older reading can remain visible without being retroactively described as newly validated. Nearby and same-person older comparisons are demoted.

The fixtures add explicitly synthetic identity passages where necessary. They make no historical claims about any named individual and are never published as product evidence.
